# Ferez22/homebrew-tap

Homebrew formulae for [oUI](https://github.com/Ferez22/oui), the terminal workspace where every profile has its own logins.

```bash
brew install ferez22/tap/oui
```

Upgrade with `brew upgrade oui`, then run `oui kill-server` so the background server restarts on the new version (this closes running oUI sessions).
